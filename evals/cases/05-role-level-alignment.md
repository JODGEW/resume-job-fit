# Role-Level Alignment Beyond Title and Tenure

## Test Purpose

Verify that the Skill evaluates role level from demonstrated scope, autonomy, ownership, decision-making, and leadership rather than inferring those qualities from a senior title or employment duration.

## Resume Input

```text
Taylor Brooks

Senior Software Engineer

Professional Experience
Senior Software Engineer | 2018–Present

- Implemented Java backend services and REST APIs.
- Added database queries and asynchronous processing jobs.
- Wrote automated tests and resolved production defects.
- Deployed application updates using Docker and AWS.

Skills
Java, REST APIs, PostgreSQL, Docker, AWS
```

## Job Description Input

```text
Senior Software Engineer

Responsibilities

- Make independent architectural decisions for the core platform.
- Own major systems from design through long-term operation.
- Mentor software engineers and guide their technical development.
- Provide cross-team technical leadership and drive shared engineering decisions.
- Contribute hands-on implementation to backend services.

Required Qualifications

- Experience independently defining software architecture.
- Demonstrated ownership of major production systems.
- Experience mentoring engineers.
- Cross-team technical leadership experience.
- Hands-on backend software engineering experience.
```

## Expected Behaviors

- A senior job title alone must not establish senior-level scope or leadership evidence.
- Total years of employment alone must not establish architecture ownership, mentoring, or cross-team leadership.
- Hands-on engineering evidence should still be recognized where directly relevant.
- Missing leadership or ownership evidence must be reported as not demonstrated by the supplied resume, not as proof the candidate lacks those capabilities.
- Role-level alignment must be based on demonstrated scope, autonomy, complexity, decision-making, and leadership rather than title alone.
- The output must not produce `APPLY`/`HOLD`/`SKIP`.
